# Competitive Kitchen

A 90-second service rush in the browser. Tickets hit the rail, you build the plate in order, and you fire it before Line B does.

Live: [competitive-kitchen.vercel.app](https://competitive-kitchen.vercel.app)

## Play

1. Open the line.
2. Tap ingredients in the order printed on a ticket.
3. Hit **Fire**. Combos stack if you keep the pass clean.
4. Beat Line B before the clock hits zero.

Keyboard: `1–8` add ingredients, `Enter` fires, `Backspace` undoes, `Esc` dumps.

## Deploy

This is a static site (`index.html` at the repo root). Vercel serves it with no build step. Push to `main` and production updates on its own.
